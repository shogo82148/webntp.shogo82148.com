Why WebNTP

Web だけで完結する時刻同期

従来の NTP は UDP/123 を使うため、制限の厳しいネットワークやブラウザからは扱えません。WebNTP は普段の HTTP/HTTPS をそのまま使います。

どこからでも

ポート 80/443 だけで動作。ファイアウォールやプロキシの内側、ブラウザからでも時刻を取得できます。

低遅延・高精度

WebSocket なら接続を張ったまま往復遅延を測定。NTP と同じ手法でクロックオフセットを補正します。

3 つの方式

JSON over HTTP・WebSocket・Time over HTTPS ヘッダー。用途に応じて最適なプロトコルを選べます。

Quick start

3 ステップで動かす

Go さえあればサーバーもクライアントもすぐに立ち上がります。

1

インストール

shell
go install github.com/shogo82148/go-webntp/cmd/webntp@latest
2

サーバーを起動

shell
webntp -serve :8080
3

時刻に同期

shell
webntp ws://localhost:8080/websocket
同期結果の例
{"msg":"best time", "server":"ws://localhost:8080/websocket", "offset":0.000008, "delay":0.000212}
